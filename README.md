# Noisy Pups - AI

给《雨世界》的幼猫装上记忆和性格，让它们用大模型说人话。

它会记住你喂过它、抱过它、救过它，也会记住你骂过它；会自己给东西起名字，会把喜欢的东西叼来给你，会在你叫它的时候走过来。

> \\\*\\\*当前版本 0.1.0（测试中）\\\*\\\*
> 依赖：BepInEx + CreatureChat（Steam 创意工坊搜索同名模组）
> 平台：PC（Steam ），需要自己准备一个 OpenAI 兼容接口的 API Key

## 1\. 这是什么

原版幼猫只有几条固定台词。这个模组把它们换成了**有状态的对话**：

|能力|说明|
|-|-|
|**聊天**|按 `T` 打字跟它说话，它按对你的好感和自己的性格回应|
|**记事**|喂食、拥抱、救援、聊天、一起过夜，都写进它自己的账本|
|**认家长**|认准它跟随的那个人；关系崩了会自己解绑，另找合得来的|
|**起名**|给自己、给同伴、给物品起名字；玩家起名优先级最高|
|**自己行动**|发呆时会突然想到什么，然后真去把喜欢的东西捡起来塞给你|
|**听指令**|「过来」「待在这」「自由活动吧」「把灯笼拿给我」「去那只光鼠那边」|
|**送礼与收礼**|会挑东西送人，也会判断要不要收你的；送了就真的走过去递|
|**听闲话**|你说某样东西好坏，它改的是对那东西的看法，不会记成你在夸它|
|**驯服蜥蜴**|驯服的蜥蜴不再让它害怕，按性格变成亲昵或敬畏|

所有台词都由模型**当场生成**。模组自带的那份 JSON 台词库（`PupText/pup.json`）不再参与说话，一句都不会念出来。

## 2\. 它不是什么

先把预期说清楚，能省掉一半的"报错"：

* **它不是聊天机器人**：它只知道自己看见过、听说过、经历过的东西。问它没见过的，它会说"没看见"。
* **它不会替你做操作**：不帮你打怪、不帮你搬运、不会抢你的东西。
* **它不替换原版行为**：跟随、捕食、躲避、睡觉都还是原版那套，模组只在原版之上加"说话"和少量"自发行为"。
* **它不是本地模型**：需要联网调用你填的 API，会产生你自己的费用。
* **它不会读心**：你说的每句话都要先经过一次意图判断，判断错了就会答歪——这是最容易遇到的"bug"，见 [12. 报错自查](#12-报错自查)。

## 4\. 配置 AI

**没配 Key 也能进游戏，但幼猫只会回你一声「……」。**

### 4.1 拿一个 API Key

默认走 DeepSeek，也可以用任何 OpenAI 兼容接口。以 DeepSeek 为例：

1. 到 DeepSeek 开放平台注册，创建一个 API Key。
2. 记下 base url：`https://api.deepseek.com`
3. 记下模型名：`deepseek-chat`

其他服务商同理，只要兼容 `/chat/completions` 就行。

### 4.2 填进 Remix

游戏内 **Remix → Noisy Pups - AI → AI 页**：

|字段|填什么|
|-|-|
|`Enable AI generated dialogue`|保持勾选（默认已开）|
|`Base URL (OpenAI compatible)`|`https://api.deepseek.com`|
|`API Key`|你的 Key（输入框是密码模式，看不见内容是正常的）|
|`Model`|`deepseek-chat`|

填完点 **Apply / 保存**。

> ⚠️ Key 以\\\*\\\*明文\\\*\\\*保存在配置里，别把配置文件发给别人。

### 4.3 测试连接

同一个页面往下，点 **Test connection**。几秒后按钮右边会显示结果：

* 显示成功 / 返回内容 → 通了，进游戏按 `T` 就能聊。
* 显示超时、401、403、404 → 看 [12-B](#b-ai-连不上--回省略号)。

### 4.4 建议第一次这样设

|选项|建议值|原因|
|-|-|-|
|`Wait for AI (ms)`|2000|网络差可以调到 3000–5000，代价是它"想"得更久|
|`Max tokens`|200|推理型模型要留思考空间，调小了会返回空|
|`Temperature`|110（1.10）|越高越跳脱，太低会变成复读机|
|`Talk interval`|12|觉得烦就调大到 20–30|

## 5\. 上手：三分钟

1. **进一个有幼猫的存档**（或去 Remix 打开「成年猫也当幼崽」用成年猫试）。
2. **靠近它**，按 `T`，输入「你叫什么名字」，`Enter` 发送。

   * 它还没名字 → 会当场给自己起一个。
   * 已经有名字 → 报出名字。
3. **夸它一句**：「你真好」。它会开心，好感上升。
4. **骂它一句**：「你真笨」。它会不高兴——勇敢高的会顶嘴，胆小的会沉默。
5. **给它起名**：「以后你就叫白糖」。这是家长权限，能覆盖任何旧名。
6. **要它拿东西**：「把灯笼拿给我」。它会转身去捡，然后走到你面前递过来。
7. **让它待着**：「待在这」。它会站住不动，直到你说「自由活动吧」。

输入框的操作：`Enter` 发送，`Esc` 取消，`Ctrl+V` 粘贴。

> 说话不只有你能触发：它会自己在发呆、看见捕食者、被抓、被喂的时候开口。不想太吵就调 `Talk interval`。

## 6\. 它能听懂什么

**不是关键词匹配**。每句话先经过一次模型判断，解析成一组标签，再合成一个意图。所以**意思对就行，说法不必一字不差**。

### 6.1 改它对「你」的态度

|你说|它会|
|-|-|
|「你真好」「我喜欢你」「别怕」|好感上升、情绪被安抚|
|「你真笨」「滚开」「再过来我打你」|好感下降；勇敢/尊严高的顶嘴，胆小的沉默|
|「我没骂你」「是我说错了」|止损消气，不会继续记仇|

### 6.2 起名与问名

|你说|它会|
|-|-|
|「你叫白糖」「以后就叫白糖」|改名。玩家来源，优先级最高|
|「这个玩偶叫毛毛」|给那件东西起名，写进记忆，以后一直这么叫|
|「你给它起个名字」|自己想一个，用闲聊语气说出来，同时落盘|
|「你叫什么」|报名字；没名字就当场起一个|
|「矛叫什么名字」|翻记忆回答；没印象就说「没见过这东西」，不会瞎猜|

> 起名/问名要指定对象时，编号只能从它\\\*\\\*当前看得见的东西\\\*\\\*里挑（320 像素内，最多 16 个）。看不见的它会老实说没看见。

### 6.3 送礼与取物

|你说|它会|
|-|-|
|「把灯笼拿给我」|手上没有就先走过去捡，再走到你身边松手/塞给你|
|「这个果子给你」|判断收不收（对你好感、对东西喜好、有没有空手）|
|「你把这个送给雪牙」|不插手，只记一笔"这人挺大方"|

* 送礼是**真的会走路**的：设目标 → 走过去 → 到 56 像素内递交。
* 你手空着的时候，它会直接把东西**塞进你手里**；你两只手都满了就放地上等你自己捡。
* AI 同伴收礼要过判定，拒收的话东西会留在送礼者手里。

### 6.4 去哪（指令）

|你说|它会|
|-|-|
|「过来」「来我这儿」|走到你**说话时**站的位置，然后停住（不会一直跟着）|
|「去灯笼那里」「到那只光鼠那边」|走到那个东西/生物旁边停住|
|「待在这」「别动」「在这儿等着」|停在原地，直到你取消|
|「自由活动吧」「不用跟着我了」|解除停留，恢复自由|

* 取消的另一种方式：它开始做别的事（比如送礼），停留会自动解除。
* 「去某处」只在**同一房间**里找目标，跨房间会说没看见。

### 6.5 好话坏话

|你说|它会|
|-|-|
|「绿蜥蜴是好东西」「这果子真甜」|只改它**对那东西**的看法，不算夸你|
|「那家伙真讨厌」|对那东西好感下降，可能替它说话|
|「雪牙很厉害」（转述别人）|采纳这条传闻|

如果被评价的东西**就在现场**，它才会顺便对说这话的人产生一点坏印象；只是转述不算。

### 6.6 它做不到的

|你说|现状|
|-|-|
|「跟我走」「跟上我」|没有这个意图。用「过来」或陪它走|
|「去咬它」「别打」「快跑」|没有战斗指令，最多被当成一句评价|
|「用矛」「跳」「把东西扔了」|没有对应意图|
|「别捡那个」|没有对应意图，它自己决定拿什么（只对喜欢的下手）|

## 7\. 它自己会做什么

不需要你说话，它每隔 26–48 秒会"走神"一次，想点什么，然后可能真的去做：

* 把喜欢的东西捡起来，走到你身边递给你
* 走到某个它在意的东西旁边
* 给某样东西起个名字
* 单纯嘟囔一句（45% 的概率会说出口，其余是心里话）

**前提**：目标得在同一个房间、320 像素内，而且它对你/那东西的好感要够（生物 > 0.15，物品 > 0.05）。所以它不会去捡路边随便一块石头。

它还会在抱你、被抱、被喂、被抓、逃跑、挨打、下雨、饿、困、醒来这些时刻主动开口。

## 8\. 它记得什么

每只幼猫一份独立的记忆：

|记的东西|内容|
|-|-|
|**印象**|每个生物/物品一条：好感、熟悉、恐惧、标签、被喂过几次、被抱过几次、救过、聊过、一起待过|
|**事件**|看见、被救、被夸被骂、听说的传闻、起名，都带时间和来源|
|**家长**|以原版"幼崽正在跟随谁"（`friendTracker.friend`）为准，不是猜的|
|**名字**|自己的、玩家的、同伴的、物品的，各存各的，按存档 ID 精确对应|

关于**家长**：

* 它以「原版跟随目标」为准。你抱着它、或者它正跟着你，家长就是你。
* 如果当前家长的好感**跌破 0**，它会解绑，然后自己去找好感够高的下一个。
* 双人局里，P2 临时抱起它不会顶掉家长身份；但如果你把 P2 的关系处坏了，它会真的改认别人。

## 9\. 选项详解

全部在 **Remix → Noisy Pups - AI**。

### Dialogue 页

|界面标签|默认|作用|
|-|-|-|
|`Enable swear blocking`|开|启用屏蔽词过滤（读 `PupText/blockedWords.txt`）。命中时这句直接作废|
|`Enable adult cat talk`|关|成年猫也按幼猫对待（能聊天、能收礼）。**不会接管你的操作**|
|`Select the enabled language pack`|pup|语言包下拉。当前只影响内部状态标签，不影响实际台词|
|`Chattiness`|100%|整体话量。30% 很安静，200% 很吵|
|`Minimum chance to speak`|60%|非点名场合的最低开口概率|
|`Talk interval`|12s|两次主动说话的最小间隔|
|`Reply delay`|1.8s|回复前故意停顿，显得像在思考|

### AI 页

|界面标签|默认|作用|
|-|-|-|
|`Enable AI generated dialogue`|开|总开关。关掉就等于只会「……」|
|`Base URL`|`https://api.deepseek.com`|接口地址|
|`API Key`|空|你的 Key|
|`Model`|`deepseek-chat`|模型名|
|`Max tokens`|200|单次回复上限。推理模型要留够思考空间|
|`Temperature`|1.10|越大越发散|
|`Wait for AI (ms)`|2000|等多久算超时|
|`Print decision log`|关|往 BepInEx 日志里打决策细节，排查必开|
|`AI for everyday talk too`|开|日常碎嘴也走 AI。关掉能省钱，但话会变少|
|`Disable thinking (reasoning models)`|关|推理模型（R1、GLM-Z 之类）勾上，省 token|
|`Write journey log (logs/)`|开|写旅程日志，配套工具要用|
|`Test connection`|—|发一条测试请求|
|`Clear cache`|—|清掉本地台词缓存|

## 10\. 文件与存档

### 记忆

```
Noisy Pup-AI/memories.json
```

* 每 20 秒落盘一次，不用手动保存。
* 旧版本把这个文件放在 `BepInEx/config/NoisyPupAI/memories.json`，新版本第一次启动时会自动搬过来。
* 想重置某只猫的记忆：删掉这一份文件（会连带清掉所有猫）。想只清一只，用编辑器删 `Pups` 里对应的那条。

### 旅程日志

```
Noisy Pup-AI/logs/journey-20261029-221500.jsonl
```

* 每次启动游戏新建一份，一行一件事。
* 内容包括：看见了什么、记住什么、想了什么（完整提示词 + 模型回答）、说出口什么、好感怎么变的。
* 排查问题最好用它——比 BepInEx 日志详细得多。

### 程序日志

```
Rain World/BepInEx/LogOutput.log
```

搜 `\\\[AI]`、`\\\[Talk]`、`\\\[Gift]`、`\\\[Order]`、`\\\[Namer]` 这些前缀。

## 11\. 配套工具：记忆提取器

一个**单文件网页**，双击就能用：不用装 Python、不用开服务、不用敲命令。

文件在仓库的 `tools/雨世界记忆提取器.html`，单独拷到桌面也能用（所有数据都在本地，不上传）。

### 怎么用

1. 双击 `雨世界记忆提取器.html`（Chrome / Edge 都行）。
2. 点右上角 **「一键载入（选模组文件夹）」**，选中你的 `Noisy Pup-AI` 文件夹。

   * 也可以直接把整个文件夹**拖进窗口**，效果一样。
3. 搞定。它会自己做完两件事：

   * 读顶层的 `memories.json`（记忆）
   * 在同目录的 `logs/` 里挑**修改时间最新**的那份 `journey-\\\*.jsonl`（旅程日志）

不用管文件叫什么、在哪一层——它会自己翻，只要那个文件夹里有就行。

### 页面里有什么

|页签|看什么|
|-|-|
|概览|这只猫的性格、好感、关系网|
|印象|它对每个生物/物品的看法，好感从哪来的|
|事件|按时间排列的记忆条目，可搜索、可筛选|
|台词|它说过的所有话，按时间排|
|旅程|那一局完整的时间线：看见什么、想了什么、说了什么、好感怎么变|

右上角可以导出 Markdown / CSV / JSON / TXT，或者「打包导出」成一个 zip。

### 几个使用细节

* **载入的是快照**：游戏又写了新内容，再点一次「一键载入」就好。想让页面自己跟着刷新，看下面的进阶说明。
* **也可以只拖单个文件**：`memories.json` 或某一份 `journey-\\\*.jsonl`，拖哪个读哪个。
* **文件被占用也能读**：游戏正在写日志时，最后一行可能是半截，工具会自动跳过坏行，不会报错。
* **没有任何数据也能试**：页面上有「查看示例数据」，可以先看看长什么样。

### 进阶（可选）

仓库里还留着一份 Python 版（`memory\\\_extract.py`），多了两件事：

* 开一个本地服务，**文件一变页面自动刷新**，不用反复点
* 命令行批量导出

日常查看用网页版就够了，需要自动刷新时再考虑。

## 12\. 报错自查

按现象查。每条都是「现象 → 原因 → 处理」。

### A. 装不上 / 报错红字

|现象|原因|处理|
|-|-|-|
|Remix 里找不到 `Noisy Pups - AI`|文件夹层级多了/少了一层|确保 `mods/Noisy Pup-AI/modinfo.json` 直接可见，不是 `mods/Noisy Pup-AI/Noisy Pup-AI/…`|
|模组名显示红字，说缺依赖|没装 CreatureChat|装上 CreatureChat 并勾选|
|进游戏直接闪退，日志末尾是 `TypeLoadException` / `MissingMethodException`|游戏版本和模组不匹配，或 BepInEx 版本不对|用 BepInEx 5.4.x；确认游戏是最新版|
|选项页打开是空白，只有一个 `Error` 页签|选项界面初始化失败|看 `LogOutput.log` 里的 `\\\[Option] 初始化失败`|
|装了没效果，没有任何幼猫说话|存档里没有幼猫|用有幼猫的存档，或打开「成年猫也当幼崽」|

### B. AI 连不上 / 回省略号

|现象|原因|处理|
|-|-|-|
|问它话只回「……」或 `...`|没填 Key / 关了 AI / 请求失败|先点 `Test connection` 看具体报错|
|测试返回 401 / 403|Key 错、过期、或没权限|重新生成 Key；注意别把空格和引号带进去|
|测试返回 404|Base URL 或模型名不对|DeepSeek 用 `https://api.deepseek.com` + `deepseek-chat`；有些服务要在 base url 后加 `/v1`|
|测试一直超时|网络问题 / 需要代理|把 `Wait for AI` 调大；确认游戏能走你的代理|
|显示成功但游戏里还是不回话|模型返回空（推理模型把 token 用光了）|`Max tokens` 调到 300–400；或勾上 `Disable thinking`|
|白天能用，晚上不行|额度用完 / 限流|去服务商后台看余额|

### C. 不说话 / 答非所问

|现象|原因|处理|
|-|-|-|
|完全不理我|距离太远 / 不在同一房间 / 有别的猫先接了话|靠近它再说；一次只有一只猫接话|
|不回话，但日志里有 `\\\[AI] 成功`|回复被判成"和上句太像"丢掉了|正常防复读，换个说法再问|
|回复完全不相关|意图判断错了|把话说具体一点：「这个果子给你」比「给你」好判断|
|它答的话像在念课文|Temperature 太低|调到 120–140|
|一直说同一句话|命中缓存或者模型在复读|点 `Clear cache`；或把 Temperature 调高|
|有时突然一句话都不说|可能命中了屏蔽词|检查 `PupText/blockedWords.txt`；或关掉 `Enable swear blocking` 试试|

### D. 行为不对

|现象|原因|处理|
|-|-|-|
|说「把灯笼拿给我」，它站着不动|灯笼不在同一房间，或它手上/手上都有东西|看日志 `\\\[Gift] 放弃 \| …`，后面括号会写它以为东西在哪个房间|
|送礼走到一半停下|收礼的人换了房间|只在同房间内送，跨房间会中止|
|它一直捡石头、乱抱东西|原版 Idle 状态会一直按住抓取键|这是原版行为，模组只在送礼期间临时拦一下|
|说「待在这」它还在走|指令没被识别成 MOVE|说得明确些：「待在这」「别动」；再看日志有没有 `\\\[Order]`|
|说「去雪牙那里」没反应|目标不在同房间 / 不在可见清单|靠近再说，或者先说「过来」把它叫到身边|
|它不跟着我了|当前家长的好感跌破 0，已解绑|喂它、夸它，把好感拉回来；或直接说「过来」|
|驯服的蜥蜴它还是怕|那条蜥蜴没被判成"已驯服"|驯服判定看原版 `friendTracker.friend`，得真的和它建立朋友关系|

### E. 名字相关

|现象|原因|处理|
|-|-|-|
|给它起名没生效|说话的不是家长|家长 = 它当前跟随的人；P2 改名会被拒|
|两只猫同名了|早期版本的 bug|已修：现在会拦"重复自己的名字"和"撞名"|
|它给自己起的名字很怪|模型自由发挥|直接叫它「以后你就叫 X」，玩家命名优先级最高|
|问「它叫什么」它说没印象|那只生物不在它的记忆里|让它先看见它（靠近、同房间），再问|

### F. 性能与费用

|现象|原因|处理|
|-|-|-|
|一局下来 token 消耗很快|所有事件都走 AI，没有本地说台词的省流路径|调大 `Talk interval`、调低 `Minimum chance`、关掉 `AI for everyday talk too`|
|说话有明显延迟|`Reply delay` + 网络往返|降低 `Reply delay`；换更快的模型|
|游戏卡顿|极少见，通常是请求太多|关 `AI for everyday talk too`，或减少幼猫数量|
|存档变卡|`memories.json` 太大（长期游玩会累积）|定期清理不重要的印象条目|

## 13\. 日志速查

打开 `BepInEx/LogOutput.log`，按前缀搜：

|前缀|含义|
|-|-|
|`\\\[AI] 成功 \| … 耗时=…ms 台词=…`|这次请求成功，能看到模型原话|
|`\\\[AI] 失败 \| …`|请求失败，后面跟 HTTP 状态或异常|
|`\\\[AI] 超时 \| … 回退=省略号/静默`|等太久了|
|`\\\[AI] 跳过 \| 原因=未启用或空Key`|Key 没填或 AI 关了|
|`\\\[Talk] …`|说话流程（原版事件、省略号回退）|
|`\\\[Decide] … 概率=…`|说话决策（需要开 `Print decision log`）|
|`\\\[Opinion] 判定结果 \| 意图=… 原文=…`|玩家这句话被判成了什么意图|
|`\\\[Gift] 开始送 / 送到 / 被拒收 / 放弃`|送礼全流程|
|`\\\[Order] …`|去哪类指令|
|`\\\[Namer] 忽略 \| 原因=…`|起名被拦下的原因|
|`\\\[Parent] 认定家长 / 解绑`|家长变化|

**提 issue 时最有用的三样**：`LogOutput.log` 的相关片段、那局游戏的 `journey-\\\*.jsonl`、以及你当时说的原话。

## 14\. 常见配方

**我想安静一点**
`Talk interval` → 30，`Minimum chance` → 30%，`Chattiness` → 60%

**我想它话多一点**
`Talk interval` → 6，`Minimum chance` → 85%，`Chattiness` → 150%

**我想省钱**
`AI for everyday talk too` 取消勾选（只在你主动搭话时请求）

**我想看它脑子里在想什么**
勾上 `Print decision log`，同时保持 `Write journey log`，然后用记忆提取器的「旅程」页

**我想重开一段关系**
关游戏，删 `memories.json`，再进游戏（所有猫的记忆一起清空）

## 15\. 从源码构建

需要 .NET SDK（`net48` 目标）。

```bash
git clone <repo>
cd NoisyPupAI
dotnet build src/NoisyPupAI.csproj -c Release
```

产物在 `mod/newest/plugins/NoisyPupAI.dll`，复制进模组的 `newest/plugins/` 即可。

仓库里另有一个 `tools/deploy.ps1`，会把编译结果同步到游戏的 mods 目录（**游戏开着时 DLL 被占用，要先退出游戏**）。

## 16\. 已知限制

* **只处理同一房间**：对话候选、送礼、指令目标都按房间筛。跨房间会说没看见。
* **一次只有一只猫接话**：避免一屋子猫同时开口。
* **指令 `goto` 找不到跨房间目标**：需要的话得先把它叫到同一房间。
* **成年猫当幼崽是"模拟"**：它们不会真的变成幼猫，只是参与对话和收礼。
* **强依赖模型质量**：小模型容易把「把灯笼拿给我」判成「你要送我灯笼」。换大一点的模型会明显变好。
* **语言包里那份 JSON 不再用于说话**：改它不会改变台词，只能用来放屏蔽词。
* **0.1.0 是测试版**：记忆结构和提示词都可能变，升级后行为可能有差异。

## 17\. 反馈模板

提 issue 时请带上这些，能省好几轮来回：

```
版本：Noisy Pups - AI 0.1.0
游戏版本：Steam 最新 / BepInEx 5.4.x
模型：deepseek-chat（或别的）
现象：它明明看见灯笼了，说"把灯笼拿给我"还是站着不动
我说的原话：把灯笼拿给我
期望：它走过去捡起来递给我
实际：原地站了 30 秒后不动了

日志（LogOutput.log 相关片段）：
\\\[Gift] 开始送 | 猫=白跳跳 东西=Lantern → 0（先去拿）
\\\[Gift] 放弃 | 礼物不见了（它在房间 12，我在 9）
```

**最有用的是**：`LogOutput.log` 片段 + `journey-\\\*.jsonl` + 你当时的原话。三样凑齐，基本一次就能定位。
